# Expense Tracker

A responsive expense tracker built with HTML, CSS, and JavaScript to help users record and manage their expenses.

## Live Demo

[Open Expense Tracker](https://ammughal13.github.io/Expense-Tracker/)

## Features

- Add expenses with name, amount, category, and date
- Automatically calculate total expenses
- Delete individual expenses
- Clear all expenses
- Filter expenses by category
- Validate expense inputs
- Save expenses using browser LocalStorage
- Restore saved expenses after refreshing
- Responsive layout for mobile and desktop screens

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Purpose

This project was built to practise front-end web development, DOM manipulation, event handling, arrays, objects, filtering, and browser LocalStorage.
